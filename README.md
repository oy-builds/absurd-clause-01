# The Absurd Clause Contest — Dragon Hoard Insurance Exclusion

The entry is written as a genuine insurance exclusion — Section 22.7, a liability carve-out with a defined peril and a time limit — except the insured property is a dragon's hoard. The legalese stays completely straight while the exclusions escalate from knights to riddles to "unscheduled heroism," and the deadpan punchline is that even heroism is only a coverage problem after 5 p.m.
